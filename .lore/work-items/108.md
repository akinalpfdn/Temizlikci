Developer feedback from the Phase 5 live test (2026-09-22): tried to drag an item onto the sidebar Trash row and expected it to move to the Trash, as in Finder (HIG: familiarity).

Proposal:
- Sidebar Trash row becomes a drop destination for items dragged from the list/chart; the drop runs the same `moveToTrash` path (Undo, confirmation, tree update).
- Rows (and later segments) become draggable.

Watch out: dragging file URLs out of the app also lets people drop onto Finder or the Dock's Trash, where Finder moves the file and our tree goes stale. Use an app-internal drag type (a transferable node ID) for the sidebar drop, and decide separately whether exporting file URLs to other apps is wanted.
